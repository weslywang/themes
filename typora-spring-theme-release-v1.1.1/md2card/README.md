# MD2Card × Typora 修订版

适用全部 13 款 `md2card-*.css`。保留官网主题的色系、标题装饰、列表徽标和纸张质感，将卡片布局改为连续文档布局。

## 本次修复

- 不再修改 Typora 的 `content` 滚动容器，去掉固定卡片高度与整页变换。
- 正文 16px / 1.75 行高，文档最大宽度 920px，窄窗口自动缩减留白；参考 Spring 的写作间距，不覆盖 Spring 文件。
- 使用浏览器原生列表计数，支持嵌套、非 1 起始值和三位编号；任务复选框不再与徽标重叠。
- 所有列表标记按正文首行行盒居中，不受菱形、圆点、叶片或编号自身字号影响。
- 代码块样式只作用于围栏容器，不污染 CodeMirror 内部的 `pre` 行；保留编辑器自身的代码滚动、行号和语言工具提示。
- 补充深色侧栏、光标、选区、源码与代码高亮色；适当加深低对比度文字，装饰色仍沿用官网色系。
- 玻璃拟态使用静态蓝紫渐变模拟光感，取消整页实时背景模糊和双栏列表；小红书用边框与阴影实现叠纸，不再用白色覆盖层遮挡文字。
- 安装目录中原来缺少被引用的 `md2card/base.css`，安装时必须一起补齐。

## 安装与回退

Typora 主题目录应同时包含 13 个 `md2card-*.css` 文件，以及 `md2card/base.css`。只复制单个主题 CSS 会丢失共享样式。
本次已安装旧主题的备份位于此目录的 `backups` 子目录，扩展名为 `.css.bak`；需要回退时，恢复原文件名并复制回 Typora 主题目录。
更新后切换到其他主题再切回；如果仍显示旧效果，重启 Typora。

## 验证

- `python md2card/build_themes.py --check`：转换规则回归检查，无需联网。
- `node md2card/check_themes.cjs`：使用已有 Playwright 和 Edge，在后台加载本机 Typora 的基础 CSS，检查 13 款主题 × 1200/600/360px 三档宽度，以及真实相对导入路径。可通过 `NODE_PATH` 指向已安装的依赖目录。
- 覆盖页面与代码块滚动、横向溢出、列表、复选框和文字输入，并检查 CodeMirror 内部行没有多余边框/内边距。
- 这是样式与模拟编辑结构验证，没有启动 Typora；不等同于中文输入法、全部插件、实际分页导出和超大文档的应用端测试。卡片专有页眉页脚未移植，不生成固定尺寸卡片。

重新生成：`python md2card/build_themes.py <官网主题 JS 文件>`。生成器使用官网卡片 CSS，不使用另一套公众号 CSS。
