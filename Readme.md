# Typora Themes

我的 Typora 主题与自定义 CSS 合集。

## 使用方法

1. 在 Typora 中打开 **偏好设置 → 外观 → 打开主题文件夹**。
2. 将需要的 `.css` 文件及其同名资源文件夹复制到主题文件夹。
3. 重启 Typora，然后从 **主题** 菜单中选择主题。

> Typora 更新或重装时可能覆盖内置 CSS，请不要直接修改内置主题文件。

更多信息请参考 [添加自定义 CSS](https://support.typora.io/Add-Custom-CSS/) 和 [Typora 主题说明](https://support.typora.io/About-Themes/)。
